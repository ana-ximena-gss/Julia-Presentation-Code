Daymark: from readings to a daily brief

1

Open the story

Say

Welcome, everyone. We’re going to build Daymark, a small Julia program that turns four daily temperature readings into a short report. We’ll store the readings, calculate their average, and apply one simple rule: below 20 degrees is cool, and 20 degrees or higher is warm.

Say

We’ll build the program together in an empty file, run it at a few checkpoints, and connect each new line of output to the code that produced it. By the end, we’ll have a complete report and a closer look at how Julia handles arrays, functions, loops, conditions, and strings.

Supporting material · Before the presentation

Before the presentation

  1. Make sure Julia is installed. In the presentation terminal, run julia --version and confirm it reports a version. Julia itself is required to execute the program.
  2. The Julia extension for VS Code is optional editor support. Daymark uses only Julia’s standard library; no package installation is required.
  3. Download the complete, commented reference with the button below. Open it in VS Code or another editor with File → Open File, or use the operating system’s Open With option.
  4. Keep the reference file in a separate folder. In the presentation folder, create an empty working file named daymark.jl and open a terminal in that folder. During the presentation we will build this empty working file progressively.
  5. If Julia needs to be installed on a classroom computer, notify the instructor at least three days in advance.
